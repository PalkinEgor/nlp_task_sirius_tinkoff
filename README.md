# Text Review Classification

## Задача
Обучить модель для классификации отзывов с маркетплейсов по категориям товаров, к которым они относятся. Также необходимо разметить тренировочную выборку для обучения.
Проект выполнен в рамках вступительных испытаний на "Смена ml для студентов в Сириусе".

## Структура решения
### 1. Разметка тренировочной выборки (`markup.ipynb`)
Этот ноутбук реализует автоматическую разметку тренировочной выборки. В качестве модели была использована модель `Qwen3-4B-Instruct`.
Для улучшения качества разметки в промпт добавлялась дополнительная информация: описание категорий и примеры отзывов для категорий.
Также передавались строгие правила для устойчивости разметки.

### 2. Генерация синтетических данных (`synthetic_data_generation.ipynb`)
После автоматической разметки были выявлены такие проблемы: 
1. В категорию `бытовая техника` попадают только отзывы со словом `стирка` и его словоформами.
2. В категорию `посуда` попадают только отзывы со словом `чашка` в контексте женских бюстгалтеров.
3. Отсутсвие достаточного кол-во примером для категорий: `обувь`, `украшения и аксессуары`, `товары для детей`, `электроника`, `текстиль`.
   
В качестве модели для генерации новых данных была использована модель `Qwen3-4B-Instruct`.
Для улучшения качества разметки в промпт добавлялась дополнительная информация: описание категорий и примеры отзывов для категорий. Для разнообразия отзывов в промпт
добавлялись различные стили. Генерировались отзывы про бюстгалтеры со словом `чашка` и его словоформами чтобы модель могла различать отзывы по контексту.
Аналогично для отзывов со словом `стирка` и его словоформами.

### 3. Обучение модели классификации (`learning.ipynb`)
Моделью для классификации была выбрана `ai-forever/ruRoberta-large`. Подход к обучению был выбран полный fine-tuning с scheduler для learning rate.
Данные для обучения и валидации были разделены с сохранением долей по категориям и по источнику данных (размеченные и сгенерированные).
Для увеличения разнообразия данных к ним применялись следующие аугментации:
1. Обратный перевод.
Текст последовательно переводится на английский, затем обратно на русский, что позволяет получить естественно перестроенный вариант фразы без потери смысла.
Для этой аугментации были выбраны следующие модели: `Helsinki-NLP/opus-mt-ru-en`, `Helsinki-NLP/opus-mt-ru-en`.
2. Контекстная замена токенов.
Выбирается часть токенов, они заменяются на `MASK`, и MLM генерирует новые токены взамен. Для этой аугментации была выбрана модель `cointegrated/rubert-tiny`.
3. Вставка синонима через MLM.
   
Выбирается случайное слово, рядом с ним вставляется `MASK` и дополняется при помощи MLM. Это расширение текста через добавление релевантного синонима или контекстуально близкого слова. Для этой аугментации была выбрана модель `cointegrated/rubert-tiny`.
**Лучший результат на валидационной выборке: 0.94**

### 4. Инференс модели (`inference.ipynb`)
Ноутбук с инференсом модели и разметкой тестового наобора данных.
Производительность: 7276 примеров были размечены за 62 секунды ~ 117 отзывов в секунду.
Размер батча - 16. Видеокарта - GeForce RTX 4060.
